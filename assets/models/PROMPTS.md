# Prompts for the game's 3D models

H generates each character sheet with an image generator, turns it into a 3D model with an image-to-3D tool (for example Meshy or Tripo; export GLB, about 20,000 polygons or fewer), and adds a skeleton and animations with Mixamo. The finished `.glb` goes in this folder (see "3D models" in AGENTS.md).

Every design here is our own. Classic robot action heroes are the inspiration; never name or describe an existing character in a prompt.

Each prompt asks for front, side and back views on a plain background, which is what image-to-3D tools work best from.

## Hero
The scarf is added in the game afterwards: cloth makes the 3D step harder.
